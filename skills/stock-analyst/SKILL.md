# Stock Analyst — 股票基本面分析

## 核心理念

> 买股票即买公司未来成长。技术指标是影子，基本面才是价格的锚。
> 优先淘汰垃圾公司，集中精力在业绩增长、商业模式清晰、财务健康、估值合理的公司。

## 快速使用

```bash
python3 skills/stock-analyst/scripts/analyze_stock.py <股票代码>

# 示例
python3 skills/stock-analyst/scripts/analyze_stock.py AAPL      # 苹果(美股)
python3 skills/stock-analyst/scripts/analyze_stock.py 0700.HK   # 腾讯(港股)
python3 skills/stock-analyst/scripts/analyze_stock.py 600519.SS # 茅台(A股)
python3 skills/stock-analyst/scripts/analyze_stock.py GLD       # 黄金ETF
```

**依赖安装**（如未安装）:
```bash
pip install yfinance
```

## 四步分析框架

### 第一步：业绩分析（满分4分）
- 营收增速 >15% → +2分（高增长）
- 营收增速 5-15% → +1分（稳健）
- 营收负增长 → -1分（⚠️ 警惕）
- 利润增速同理加减分

**淘汰标准**：营收连续多年停滞或负增长的公司，直接放弃。

### 第二步：商业模式（满分4分）
- 毛利率 >40% → +2分（定价权强，如茅台、苹果）
- ROE >20% → +2分（资本高效）
- 低毛利(<10%)、低ROE → 减分

**淘汰标准**：
- 业务过于复杂，看不懂的公司
- 纯服务型（商业模式差）
- 产品无定价权（毛利极低）

### 第三步：财务健康度（满分5分）
- 现金 > 总债务 → +2分（最理想）
- 自由现金流为正 → +2分（持续造血）
- 应收款/营收 < 10% → +1分（茅台标准：几乎零应收款）

**红线**：自由现金流长期为负 + 高负债 = 高风险，直接回避。

### 第四步：估值分析（满分4分）
- PE < 15 → +2分（低估）
- PE 15-25 → +1分（合理）
- PE > 40 → -1分（泡沫风险）
- 分析师目标价上涨空间 > 20% → +2分

## 综合评级标准

| 总分 | 评级 | 操作建议 |
|------|------|----------|
| ≥75% | ⭐⭐⭐⭐⭐ | 🟢 做多 |
| ≥55% | ⭐⭐⭐⭐ | 🟢 可买入 |
| ≥35% | ⭐⭐⭐ | 🟡 观望 |
| ≥15% | ⭐⭐ | 🔴 谨慎 |
| <15% | ⭐ | 🔴 回避 |

## 使用后的分析流程

运行脚本后，基于输出做深入判断：

1. **业绩好但估值贵** → 等待回调机会，设定目标买入价
2. **业绩差但股价便宜** → 便宜不是买入理由，继续观望
3. **全面优秀** → 研究行业竞争格局，确认护城河
4. **财务有红灯** → 深入查资产负债表，了解债务结构
