# 估值参考指南

## 不同行业PE基准

| 行业 | 合理PE范围 | 说明 |
|------|------------|------|
| **科技/软件** | 20-35 | 高增长预期，研发投入大 |
| **消费电子** | 15-25 | 苹果/三星等，成熟但有创新 |
| **金融/银行** | 8-12 | 重资产，杠杆高，监管严格 |
| **消费品** | 15-25 | 稳定增长，品牌护城河 |
| **医疗/医药** | 20-30 | 研发驱动，专利保护 |
| **能源/资源** | 8-15 | 周期性行业，大宗商品价格敏感 |
| **公用事业** | 12-18 | 稳定现金流，低增长 |
| **房地产** | 8-12 | 高负债，资产重 |

## 特殊资产估值

### 黄金/贵金属
- **黄金ETF(GLD)**: 跟踪现货黄金价格，无PE概念
- **判断标准**: 通胀预期、美元强弱、地缘政治
- **估值**: 历史价格区间、生产成本、央行储备需求

### 比特币/加密货币
- **无传统PE估值**
- **判断维度**:
  1. 网络效应（活跃地址数、交易量）
  2. 采用率（机构持仓、交易所流量）
  3. 宏观环境（利率、通胀）
  4. 技术面（挖矿难度、哈希率）

### REITs（房地产信托）
- **关注指标**: FFO（运营现金流）、股息率、负债率
- **合理股息率**: 4-8%（高于国债）
- **PE范围**: 10-18

## 估值方法选择

### 1. 成长型公司
- **适用**: 营收增速 > 20%
- **方法**: PEG比率（PE/增长率）
- **合理PEG**: < 1.5（PEG=1为理想）

### 2. 成熟型公司
- **适用**: 营收增速 5-15%
- **方法**: PE + 股息率
- **关注**: 现金流稳定性、分红历史

### 3. 周期型公司
- **适用**: 能源、钢铁、航运等
- **方法**: PB（市净率） + 行业周期位置
- **关键**: 在行业低谷时买入（高PB时卖出）

### 4. 亏损公司
- **适用**: 初创、高研发投入
- **方法**: PS（市销率） + 用户增长
- **警惕**: 长期无法盈利、烧钱过快

## 红绿灯估值法

### 🟢 绿灯（买入区间）
- PE低于行业历史25%分位
- 分析师目标价上涨空间 > 20%
- 自由现金流收益率 > 5%
- 股息率 > 国债收益率 + 2%

### 🟡 黄灯（观望区间）
- PE处于行业历史25-75%分位
- 目标价上涨空间 5-20%
- 估值合理但无显著折扣
- 等待更好入场点

### 🔴 红灯（卖出/回避区间）
- PE高于行业历史75%分位
- 目标价低于当前价
- 自由现金流为负 + 高负债
- 明显估值泡沫

## 交叉验证方法

1. **多指标验证**: PE、PB、PS、PEG至少2个指标显示低估
2. **历史对比**: 当前估值 vs 5年历史平均
3. **同业对比**: 与行业龙头、竞争对手比较
4. **DCF验证**: 现金流折现（如数据充分）

## 注意事项

1. **不同市场差异**:
   - A股: 政策影响大，关注政策风向
   - 港股: 国际资金流动敏感，关注美元/港币汇率
   - 美股: 机构主导，关注美联储政策、企业回购

2. **财务数据质量**:
   - 中概股: 注意VIE结构风险、审计合规
   - 新兴市场: 公司治理、透明度问题

3. **汇率风险**:
   - 投资境外市场需考虑汇率波动
   - 本币贬值可能抵消股价涨幅
