## 2. 经典量化策略研究

### 2.1 动量策略 (Momentum)

**原理**: 价格趋势会延续，涨的继续涨，跌的继续跌

**学术基础**:
- Jegadeesh & Titman (1993): 3-12 个月动量效应
- Carhart (1997): 四因子模型中的动量因子

**实现方式**:
```python
# 时间序列动量
momentum = (price - price.shift(N)) / price.shift(N)

# 截面动量 (相对强弱)
rank = returns.rank(axis=1, pct=True)
long = rank > 0.8  # 买入前 20%
short = rank < 0.2  # 做空后 20%
```

**参数**:
- 回看期: 1-12 个月
- 持有期: 1-6 个月
- 典型: 12-1 动量 (过去12个月收益，跳过最近1个月)

**港股/BTC 应用**:
- 港股: 适合，但需考虑流动性
- BTC: 强动量市场，效果显著

**预期收益**: 年化 8-15%
**典型回撤**: 20-30%

---

### 2.2 均值回归 (Mean Reversion)

**原理**: 价格偏离均值后会回归

**实现方式**:
```python
# 布林带均值回归
sma = price.rolling(20).mean()
std = price.rolling(20).std()
z_score = (price - sma) / std

# 信号
long_signal = z_score < -2  # 超卖买入
short_signal = z_score > 2   # 超买卖出
```

**参数**:
- 回看期: 5-60 天
- 入场阈值: 1.5-2.5 标准差
- 出场: 回归到均值

**港股/BTC 应用**:
- 港股: 适合震荡市
- BTC: 波动大，需宽阈值

**预期收益**: 年化 6-12%
**典型回撤**: 10-20%

---

### 2.3 趋势跟踪 (Trend Following)

**原理**: 跟随市场大趋势，不预测方向

**经典策略**:
- 海龟交易法 (Turtle Trading)
- 双均线交叉
- 突破策略

**实现方式**:
```python
# 双均线策略
fast_ma = price.rolling(10).mean()
slow_ma = price.rolling(50).mean()
signal = np.where(fast_ma > slow_ma, 1, -1)

# 海龟突破
high_20 = price.rolling(20).max()
low_20 = price.rolling(20).min()
entry_long = price > high_20.shift(1)
entry_short = price < low_20.shift(1)
```

**参数**:
- 快均线: 5-20 天
- 慢均线: 20-200 天
- 突破周期: 20-55 天

**港股/BTC 应用**:
- 港股: 趋势较弱，需过滤
- BTC: ⭐ 完美适配，趋势性强

**预期收益**: 年化 10-25%
**典型回撤**: 15-25%

### 2.4 因子投资 (Factor Investing)

**原理**: 系统性风险溢价来源

**经典因子**:
| 因子 | 描述 | 预期溢价 |
|------|------|----------|
| Value | 低估值 (PB, PE) | 3-5% |
| Size | 小市值 | 2-4% |
| Momentum | 动量 | 4-8% |
| Quality | 高质量 (ROE, 低负债) | 2-4% |
| Low Vol | 低波动 | 2-3% |

**多因子模型**:
```python
# 因子得分
value_score = -df['PE'].rank(pct=True)
momentum_score = df['return_12m'].rank(pct=True)
quality_score = df['ROE'].rank(pct=True)

# 综合得分
composite = 0.3*value_score + 0.4*momentum_score + 0.3*quality_score
```

**港股/BTC 应用**:
- 港股: ⭐ 非常适合
- BTC: 不适用 (单一资产)

**预期收益**: 年化 8-15%
**典型回撤**: 15-25%

### 2.5 配对交易 (Pairs Trading)

**原理**: 利用相关资产的价差回归

**实现方式**:
```python
# 协整关系
from statsmodels.tsa.stattools import coint
score, pvalue, _ = coint(price_A, price_B)

# 价差
hedge_ratio = np.polyfit(price_A, price_B, 1)[0]
spread = price_B - hedge_ratio * price_A

# 交易信号
z_spread = (spread - spread.mean()) / spread.std()
long_spread = z_spread < -2
short_spread = z_spread > 2
```

**适用对象**:
- 同行业股票对
- ETF 与成分股
- 跨市场套利

**港股/BTC 应用**:
- 港股: 适合 (AH 股价差)
- BTC: 交易所间套利、期现套利

**预期收益**: 年化 5-10%
**典型回撤**: 5-15%

### 2.6 机器学习策略
